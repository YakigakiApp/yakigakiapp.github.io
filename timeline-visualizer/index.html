Timeline Visualizer

Google マップのタイムラインを地図で描く

JSON をドロップ またはクリックしてファイルを選択

選択したファイルの中身は、読込みから地図上への描画まで、すべてお使いの端末の中だけで処理されます。外部に送信されることも、保存されることもありません。

タイムラインの書き出し方

iPhone

Google マップアプリ → プロフィール写真 → 設定 → 個人的なコンテンツ → タイムライン データをエクスポート → ファイルに保存

Android

マップアプリではなく端末の設定から。設定 → 位置情報 → 位置情報サービス → タイムライン → タイムライン データをエクスポート → 続行 → 保存先を選ぶ

保存されるのは location-history.json です。項目名は端末や時期によって多少異なる場合があります。
